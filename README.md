## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- pip package manager

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tarunjit45/HandWave-Volume-Controller.git
   cd HandWave-Volume-Controller
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python main.py
   ```
